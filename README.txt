FUEL MONITOR - Android Studio project
Initial record included: Oct 7, 2026; odo 95,301 to 95,632 km; 30.47 L; 331 km; 10.86 km/L.

BUILD APK:
1. Install Android Studio (with Android SDK).
2. Open this folder as a project.
3. Allow Gradle sync and install SDK Platform 35 if prompted.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK is typically app/build/outputs/apk/debug/app-debug.apk.
6. Copy APK to your Android phone and install (allow install from this source).

App features: local records, automatic distance and km/L, fuel cost, history, CSV export, JSON backup/import.
Data is stored in WebView local storage on device. Export backups regularly; clearing app storage removes records.
